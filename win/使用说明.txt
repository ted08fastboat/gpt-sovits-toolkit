GPT-SoVITS Windows 轻量安装包 · 使用说明
================================================================

【这是什么】
  一个把 GPT-SoVITS 语音克隆环境装到 Windows 上的安装包：
  脚本 + 训练好的音色权重（示例音色）。依赖库和预训练模型由安装器联网下载。
  ≈ 需要下载 4GB、硬盘占用约 12GB。

【环境要求】
  · Windows 10 / 11（64 位）
  · 联网（安装阶段需要；装完之后合成可以离线）
  · 硬盘剩余 12GB 以上
  · 有 NVIDIA 显卡会快很多；没有也能用（纯 CPU，一句 20 字约 10~30 秒）

【安装步骤】
  1. 把本文件夹整个解压出来（不要只拖出里面的文件）
  2. 双击「install.bat」（如果中文文件名显示正常，双击「安装.bat」也一样）
     · 没装 Python 时，脚本会自动下载安装 Python 3.10.11
     · 中途会让你选「有没有 NVIDIA 显卡」，没有就直接回车
     · 想跳过这个提问：命令行执行  install.bat --no-cuda  或  install.bat --cuda
  3. 等它跑完（视网速 20~60 分钟），最后会自动播放一句自检语音

  安装完成后，程序装在：C:\Users\<你的用户名>\GPT-SoVITS

【怎么用】
  ① 声音工坊（网页界面，推荐先用这个）
     双击 C:\Users\<用户名>\GPT-SoVITS\启动声音工坊.bat
     浏览器自动打开 http://127.0.0.1:8000
     界面里能：输入台词合成、切换/上传参考音色、改参考文字、试听与下载成品、删除输出。
     模型只加载一次（首次约 1 分钟），之后每次合成只要几秒到十几秒。
     停止服务：关掉那个命令行窗口。

  ② 一键克隆（命令行，最快）
     双击「一键克隆.bat」→ 输入台词回车 → 等 30~60 秒 → 自动播放
     成品在 C:\Users\<用户名>\GPT-SoVITS\输出音频\

  ③ 批量克隆
     把句子一行一句写进「GPT-SoVITS\台词.txt」，双击「批量克隆.bat」

  ④ 官方 WebUI（功能最全，含训练）
     双击「启动WebUI.bat」→ 浏览器打开 http://127.0.0.1:9874
     用法：进「1-GPT-SoVITS-TTS」→「1C-推理」，
           上传参考音频 → 填参考文本和目标文本 → 点合成
     注意：模型默认已经是「示例音色」那套权重。

  ⑤ 给程序调用的 API
     双击「启动API.bat」，文档 http://127.0.0.1:9880/docs

  以上 ①~⑤ 共用同一套参考音色目录（GPT-SoVITS\参考音频\）与输出目录（GPT-SoVITS\输出音频\），
  在网页界面里上传的音色，一键克隆也能直接用。

【想更像？换参考音频】
  位置：C:\Users\<用户名>\GPT-SoVITS\参考音频\
    ref.wav   3~10 秒、单人、干净、无背景音乐的人声
              （mp3 / m4a 也行，文件名同样叫 ref.mp3 / ref.m4a）
    ref.txt   这段音频的逐字文字
  「备用」子文件夹里放了几个现成音色（女声-婷婷、男声-Reed），
  想切换就把某个文件复制出来改名为 ref.wav / ref.txt。

  为什么重要：GPT-SoVITS 是零样本机制 —— 音色基调来自权重，
  而音高、语气、语速由参考音频主导。实测同一套权重：
  参考音用女声（婷婷）→ 输出 244Hz 女声；换成男声（Rocko）→ 输出 102Hz 男声。

【常见问题】
  · 双击「安装.bat」一闪而过：右键 →「以管理员身份运行」，或先解压再双击
  · 提示缺少 Visual C++ 运行库：装一下微软官方 VC++ 2015-2022 x64 运行库
  · 下载很慢：安装器默认走国内镜像（hf-mirror / 清华 PyPI）。
    如果你在国外，可编辑 install.py，把 HF_MIRRORS 里的 huggingface.co 调到第一位
  · 报 OSError / 文件被占用：关掉杀毒软件的实时防护再重跑安装
  · 想换成 CUDA 版：删掉 GPT-SoVITS\venv 后重新双击「安装.bat」，选择「有显卡」
  · 日文/粤语/韩语不可用（这些语言的依赖需要编译环境），中文英文正常
  · 长文本合成慢：按标点自动切句逐句合成，属于正常现象

【声明】
  · 包内附带的音色权重来自第三方（作者或原说话人的声音），
    请勿用于冒充他人、诈骗或其它违法用途；转发给他人前请确认这没问题。
