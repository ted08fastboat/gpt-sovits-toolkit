# GPT-SoVITS 本地部署说明（macOS Apple Silicon / CPU 推理）

安装时间：2026-09-25　安装位置：`~/GPT-SoVITS`

## 一、怎么启动

**方式 1（推荐）** 打开「终端」，执行：

```bash
~/GPT-SoVITS/start-webui.sh
```

**方式 2** 在 Finder 里双击 `~/GPT-SoVITS/启动WebUI.command`

启动后浏览器会自动打开，地址是 **http://127.0.0.1:9874**
首次启动需要 1~2 分钟加载模型（BERT / HuBERT / GPT / SoVITS / G2PW），终端出现 `Running on local URL` 即就绪。
停止服务：回到终端按 `Control-C`。

启动 API 服务（给程序调用）：`~/GPT-SoVITS/start-api.sh` → 文档 http://127.0.0.1:9880/docs

## 二、零样本语音克隆怎么用

进入页面后选择 **「1-GPT-SoVITS-TTS」→「1C-推理」**：

| 项 | 填什么 |
|---|---|
| 参考音频 | 3~10 秒、干净无背景音乐的真人语音（wav/mp3/m4a 都行） |
| 参考文本 | 上面这段音频对应的文字（中文） |
| 目标文本 | 你想让它读出来的内容 |
| 参考语言 / 目标语言 | 中文 |
| 模型版本 | 默认 **v2Pro**；想要更好音色相似度可切到 **v2ProPlus** |

然后点「合成语音」，几秒后即可播放/下载。

**没现成参考音频？** 用「0-前置数据集获取工具」里的 `音频自动切分工具` 把长音频切成 3~10 秒片段；人声/伴奏分离用 `UVR5`（需要 ffmpeg，本环境已内置，无需另装）。

**小技巧**：参考音频越干净、情绪平稳、时长 5 秒左右，克隆越像；目标文本里中英混排时语言选「多语种混合」。

## 五、本机环境说明（重要）

- **只走 CPU 推理**：GPT-SoVITS 官方主推 CUDA，Apple Silicon 的 MPS 只在少数模块可用，主推理路径不支持，所以这里的 `device` 自动为 `cpu`。
  实测：一句 25 字左右的中文，合成耗时约 **5~8 秒**（不含首次加载模型的 1~2 分钟）。
- **不支持训练/微调**：本项目训练需要 CUDA，Mac 上只能 CPU 训练，速度极慢，本次仅配置了推理所需内容。
- **语种**：中文、英文可用；**日文/粤语/韩语未启用**（`pyopenjtalk`、`ToJyutping` 等在 Apple Silicon 上需要自行编译，本次未安装）。需要时可在 `venv` 里补装。
- **网络**：本机直连 `huggingface.co` 不通，已统一改走 `hf-mirror.com`（启动脚本里已设 `HF_ENDPOINT`）。所有模型已本地化，**离线也能正常推理**。
- **Python 依赖来源**：`uv` + 独立 CPython 3.11.14，PyPI 走清华镜像；关键版本 `torch 2.6.0 / torchaudio 2.6.0 / numpy 1.26.4 / gradio 4.44.1 / transformers 4.57.6`。
- **ffmpeg**：通过 `imageio-ffmpeg` 内置的 arm64 静态版提供，链接在 `venv/bin/ffmpeg`，供格式转换/UVR5 使用（无 ffprobe）。
- **内存占用**：模型加载后约 2~3 GB，建议同时别开太多大程序。

## 六、常见问题

1. **启动报端口被占用**：改 `config.py` 里的 `webui_port_main = 9874`，或先关掉占用的进程。
2. **合成报缺模型**：确认 `GPT_SoVITS/pretrained_models/` 里的文件没被移动；`test/` 下有自检脚本可跑 `~/GPT-SoVITS/smoke_test.sh ~/GPT-SoVITS v2Pro`。
3. **WebUI 默认监听 0.0.0.0**（官方默认，同一局域网可访问）。若只想本机访问，把 `webui.py` 末尾 `server_name="0.0.0.0"` 改成 `"127.0.0.1"`。
4. **换模型/加模型**：把权重放进 `GPT_SoVITS/pretrained_models/`，在界面「模型列表」下拉里刷新即可。
5. **合成有杂音/不像**：优先换更干净的参考音频；或把参考文本改成与音频完全一致的转写；ProPlus 模型相似度更好。
6. **想重装/卸载**：直接删除整个目录即可 —— `rm -rf ~/GPT-SoVITS`。
